# Hari Mohamed Rizq: logo usage

Mark: custom MR monogram (M and R share one stem). Wordmark: HARI, with MOHAMED RIZQ as a secondary line. Accessible name for every use: "Hari Mohamed Rizq".

| File | Use |
|---|---|
| symbol-{black,white,mint,green}.svg | Standalone mark, avatars, footer, social |
| horizontal-*.svg | Symbol + HARI + MOHAMED RIZQ; use at 64px height or more |
| horizontal-compact-*.svg | Symbol + HARI; use below 64px height (navbar) |
| favicon.svg, favicon-32.png, apple-touch-icon.png (180px) | Dark tile, mint heavy-cut mark (stems thickened for 16px). No root favicon.ico is shipped: a routing test expects /favicon.ico to return the 404 page |

Colour (from the existing site tokens): mint #44E6A9 on #09090b = 12.45:1; white #f8fafc on #09090b = 19.02:1; ink #111111 on #f6f8f7 = 17.70:1. On light backgrounds use ink or green #168b68 (4.00:1: passes 3:1 for graphics, not 4.5:1 for text). Never use mint on light (1.50:1).

Clear space: 1 stem width of the symbol (24 units, about 1/7 of its height) on all sides. Minimum sizes: symbol 16px (favicon cut only), full horizontal 64px height, compact 24px height.
Do not: stretch, recolour outside the palette, add gradients or shadows, outline or rotate, place mint on light, or set the secondary line below 64px lockup height.

Limits: letters are hand-constructed paths in a geometric grotesque style, not a licensed typeface. No trademark search has been done.
